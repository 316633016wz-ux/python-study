🐙 GitHub 学习总结

学习日期：2026-06-18  |  学习时长：1天

一、Git 是什么？GitHub 是什么？

工具作用类比
Git本地版本控制工具本地的"时光机"，记录每次修改
GitHub代码云端托管平台网盘 + 协作平台，存到云端可共享
📌 Git 是工具，GitHub 是网站。离线也能用 Git，GitHub 只是存代码的地方之一。

二、完整工作流程

git init→ git add→ git commit→ git remote add→ git push

三、核心命令速查

命令作用类比
git init初始化本地仓库建一本新日记本
git status查看文件状态看日记本目前写了啥
git add .暂存所有修改把草稿放进信封
git commit -m "说明"提交，生成版本快照封好信封并写备注
git log --oneline查看提交历史翻日记目录
git remote add origin URL连接远程仓库把邮局地址记下来
git push -u origin main推送到 GitHub把信寄出去
git pull从远程拉取更新收信

四、.gitignore 文件

放在项目根目录，告诉 Git 哪些文件不需要跟踪。

# Python 常用忽略规则
__pycache__/
*.pyc
.env
.vscode/
*.log
📌 __pycache__ 是 Python 自动生成的缓存，不需要上传到 GitHub。

五、GitHub Token 认证

GitHub 2021年起不再支持密码推送，改用 Personal Access Token（PAT）。

概念说明
Token 是什么GitHub 生成的临时"门禁卡"，代替密码使用
在哪生成GitHub → Settings → Developer Settings → Personal Access Tokens
需要哪个权限勾选 repo（完整仓库权限）
只显示一次生成后要立即保存，关掉页面就看不到了
Windows 会记住第一次输入后凭据管理器自动保存，不用每次输
⚠️ Token 不要分享给别人，丢了就在 GitHub 重新生成一个（旧的作废）。

六、国内网络问题解决

GitHub 在国内经常连不上，需要配置代理：

# 设置 git 使用本地代理（端口改成自己的，Clash 默认 7890）
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890

# 取消代理（出国后或不用梯子时）
git config --global --unset http.proxy
git config --global --unset https.proxy

八、下次更新代码步骤

以后每次写完代码，只需三步：

git add .
git commit -m "描述做了什么"
git push
⚠️ 常见错误：git add.（错）→ git add .（对）
add 和 . 之间必须有空格，否则 git 认不出这个命令。
