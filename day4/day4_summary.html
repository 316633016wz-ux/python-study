Day 4 学习总结：文件读写、路径、编码

日期：2026-06-23  |  Python 学习计划 Day 4

1. 打开文件 open()

open("文件名", "模式", encoding="utf-8")

三件事：建通道 → 读/写 → 关闭。中文文件始终加 encoding="utf-8"，否则乱码。

原理（图书馆比喻）：open 像找到书，read 像把内容抄进笔记本（内存），关闭像还书。硬盘存的是字节，encoding 决定按什么规则把字节翻译成文字。

2. with 语句（推荐写法）

with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()
# 块结束自动关文件，不用手写 f.close()

3. 三种常用模式

模式作用文件不存在时文件存在时
r只读报错正常读
w写入自动创建清空重写
a追加自动创建末尾添加
注意：w 会清空原文件，小心别覆盖重要内容。

4. 三种读取方式

方法返回特点
f.read()一个字符串全部内容
f.readlines()一个列表每个元素是一行
for line in f逐行省内存，按 \n 分行

5. 路径

类型写法说明
相对路径"test.txt"在当前运行目录找
绝对路径r"D:\...\test.txt"从盘符找，更稳

r"..."：前面加 r 让 \ 不被当转义符，是 Windows 路径的标准写法。

6. 本日新工具

  • line.strip()：去掉首尾空白和 \n
  • print(x, end='')：打印后不自动换行（默认 end 是 \n）
  • f"...{值}..."：f-string，自动把 {} 里的值填进去，数字也不用 str() 转换
  • len(列表)：直接拿到元素个数

7. for 循环核心理解

for 变量 in 容器:
    循环体
  • 容器决定怎么切：列表→元素、字典→键、文件→按 \n 分行、字符串→字符
  • 变量名随便取，Python 自动把切出来的东西赋值给它

8. 综合练习

读 output.txt 统计行数，写入 result.txt：

with open("output.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()

with open("result.txt", "w", encoding="utf-8") as f:
    f.write("文件内容：\n")
    for line in lines:
        f.write(line)
    f.write(f"\n总行数为：{len(lines)}\n")

常见报错

报错原因
FileNotFoundError文件不存在或路径不对
TypeError: write() argument must be strreadlines() 是列表，write() 只收字符串，要逐行写或 "".join()
