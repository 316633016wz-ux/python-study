Day 6 学习总结：CSV 文件 + pandas 数据处理

本节学习了用 pandas 处理表格数据，这是数据分析和 AI 工作中最常见的任务。

1. 什么是 CSV 文件

CSV = Comma-Separated Values（逗号分隔值），是用逗号隔开的纯文本表格数据，可以用 Excel 打开。

姓名,语文,数学      ← 第一行是表头（列名）
小明,85,90         ← 之后每行是一条记录
小红,92,88
小刚,78,85

2. pandas 两个核心结构

结构含义类比
DataFrame整张表格（有行有列）Excel 表 / 二维数组
Series表格里的一列一维数组

3. 深入理解 Series（一列数据）

Series 就是 DataFrame 里的一列，是带行号的一维数据。你写 df["语文"] 得到的就是一个 Series：

0    85
1    92
2    78
Name: 语文, dtype: int64
  • 左边 0 1 2 是索引（行号）
  • 右边是值
  • Name: 语文 是这列的名字
  • dtype: int64 是数据类型（整数）

也可以单独创建一个 Series：

import pandas as pd

s = pd.Series([85, 92, 78])
print(s)

Series 常用方法：s.mean() 平均值、s.max() 最大值、s.min() 最小值、s.sum() 求和。

Series 和 DataFrame 的关系：
Series = 一列（一维）；DataFrame = 多个 Series 拼成的表格（二维）。
就像 C 语言里：一维数组 vs 二维数组。

5. 第一个 pandas 程序

import pandas as pd

data = {
    "姓名": ["小明", "小红", "小刚"],
    "语文": [85, 92, 78],
    "数学": [90, 88, 85]
}

df = pd.DataFrame(data)
print(df)

6. 重点理解：布尔索引

df["数学"] > 88 不是直接筛行，而是先返回一列 True/False：

0     True   ← 90 > 88 是真
1    False
2    False

外面套 df[...] 的意思是「只保留 True 对应的行」：

df[df["数学"] > 88]   # 只留下数学大于88的行
对比 C 语言：
pandas 一行 df[df["数学"] > 88] 等价于 C 里写 for 循环 + if 判断逐行检查，但 pandas 不用写循环。

7. 找最高/最低值对应的行

错误写法（会报错）：df.loc[df["总分"].max(), "姓名"]
因为 .max() 返回的是数字（如 600000），被当成行号去找，找不到就报错。

正确写法（两步）：

最高分 = df["总分"].max()
print(df.loc[df["总分"] == 最高分, "姓名"])

8. 常见报错与注意点

问题原因 / 解决
FileNotFoundError当前目录没有该文件，检查文件名拼写和 cd 目录
KeyError: '列名'列名拼错了，对照 DataFrame 里真实的列名
方法不生效 / TypeError方法必须加括号：.mean() .max() .describe()
Excel 打开中文乱码保存时用 encoding="utf-8-sig"
f-string 引号冲突外层双引号，内层用单引号：f"{df['列名']}"
小贴士： utf-8-sig 比 utf-8 多了一个 BOM 标记，Windows 的 Excel 靠它识别 UTF-8 编码，避免中文乱码。有中文 + 要用 Excel 打开就用它。
