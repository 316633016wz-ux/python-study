一、函数 Function

C 里要声明返回类型，Python 直接用 def，靠缩进区分函数体。

C 语言Python
int add(int a, int b)def add(a, b):
要声明类型 + 花括号不用类型，冒号 + 缩进
def add(a, b):
    return a + b

x = add(3, 5)   # x = 8

二、字符串 String

Python 字符串自带方法，比 C 的 string.h 简单太多。

方法作用C 语言对应
len(s)长度strlen()
s.upper() / s.lower()转大/小写遍历 toupper()
s.replace(旧, 新)替换手写循环
s.split(分隔符)切割成列表strtok()
s.strip()去两边空格手写
"x" in s判断是否包含strstr()
💡 replace 只替换指定内容，不影响大小写。

三、列表 List

类似 C 数组，但不用声明长度、可混放类型、支持负索引和切片。

操作作用
fruits[0]第一个元素
fruits[-1]倒数第一个（C 做不到）
append(x)末尾添加
insert(i, x)指定位置插入
remove(x)删除第一个值为 x 的元素
sort()排序（直接改原列表）
列表[1:4]切片，取索引 1~3（不含 4）

四、字典 Dict

键值对结构，C 里没有，要用结构体数组模拟。用键访问，不用数字索引。

student = {"name": "小明", "age": 22}

student["name"]          # 用键访问 → 小明
student["goal"] = "AI"   # 添加新键值对
"age" in student         # 判断键是否存在 → True

for key in student:      # 遍历所有键
    print(key, student[key])
⚠️ 易错点：字典没有数字索引。stock[0] 会报 KeyError，必须用键 stock["苹果"]。遍历直接 for key in stock:，不要加切片。

五、综合作业：水果库存

def add_fruit(stock, name, count):
    if name in stock:
        stock[name] += count    # 已有则累加
    else:
        stock[name] = count     # 没有则新增

stock = {}
add_fruit(stock, "苹果", 5)
add_fruit(stock, "香蕉", 3)
add_fruit(stock, "橙子", 8)

for key in stock:
    print(f"{key}库存{stock[key]}个")

print(f"共{len(stock)}种水果")
✅ 这道题综合用到了：函数 + 字典 + 遍历 + len()。加 if name in stock 判断让重复水果累加，是很好的细节。
