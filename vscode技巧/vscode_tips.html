⚡ VS Code 使用技巧

适用：Python 学习 | 整理日期：2026-06-22

一、最常用快捷键

操作快捷键说明
注释 / 取消注释Ctrl + /选中多行同样有效
运行 Python 文件Ctrl + F5不调试直接运行
保存文件Ctrl + S养成习惯，随时保存
撤销Ctrl + Z多次撤销
重做Ctrl + Y撤销撤销
全选Ctrl + A
查找Ctrl + F当前文件内搜索
替换Ctrl + H批量替换文本
格式化代码Shift + Alt + F自动整理缩进
命令面板Ctrl + Shift + P搜索所有 VS Code 命令
打开终端Ctrl + `反引号，键盘左上角
向上/下复制整行Shift + Alt + ↑/↓快速复制代码行
移动整行Alt + ↑/↓调整代码顺序
删除整行Ctrl + Shift + K
多光标编辑Alt + 鼠标点击同时编辑多处

二、Python 专用技巧

技巧操作方式
自动补全输入时按 Tab 或 Enter 确认
查看函数说明鼠标悬停在函数名上
跳转到定义F12 或 Ctrl + 鼠标点击
查看报错详情红色波浪线处悬停，或看终端输出
选中整段缩进块点击行号左边可折叠/展开代码块

三、终端使用

操作命令
运行 Python 文件python 文件名.py
切换目录cd 路径
查看当前目录文件ls（PowerShell）
清空终端cls（PowerShell）
上一条命令↑ 键

四、常见报错排查

现象原因解决
IndentationError缩进不一致（空格和Tab混用）统一用4个空格
SyntaxError括号/引号没配对，或冒号漏了检查报错行
NameError变量名拼写错误或未定义检查变量名
文件跑完没反应没保存，或路径不对Ctrl+S 后再运行
中文乱码文件编码不是 UTF-8右下角点编码→UTF-8

五、实用小习惯

💡 每次运行前先 Ctrl+S 保存，VS Code 不会自动保存。
💡 Ctrl+/ 注释掉不用的代码比删除好，方便对比和恢复。
⚠️ git add . 中间有空格，git add. 是错误写法。
