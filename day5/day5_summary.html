二、核心知识点总结

1. 字典操作（练习 1 核心）

添加或修改键值对：

scores[name] = score  # 键不存在→添加，键存在→修改

遍历字典（同时拿键和值）：

for name, score in scores.items():
    print(f"{name}: {score}")
和 C 语言对比：
C 数组只能用数字下标 [0][1][2]
Python 字典可以用字符串做键 ["张三"]["李四"]

2. 文件操作三种模式

模式 说明 文件不存在 用途
"r" 只读 报错 读取已有文件
"w" 清空重写 创建新文件 保存最终结果
"a" 末尾追加 创建新文件 日记、日志等累积内容

3. 文件读取方式对比

方法 返回类型 是否保留 \n 适用场景
f.read() 字符串 是 小文件，一次性读取
f.readlines() 列表 是 需要行列表
for line in f 逐行字符串 是 大文件，省内存（推荐）
重要：无论用哪种方式读取，每行末尾都有 \n 换行符，要用 line.strip() 去掉！

4. 字符串处理

strip() - 去掉首尾空白：

line = "  张三,85\n  "
line.strip()  # "张三,85"

split() - 按分隔符切割：

line = "张三,85"
name, score = line.split(",")  # name="张三", score="85"
注意：split() 返回的都是字符串，数字要用 int() 转换！

5. try...except 错误处理

try:
    with open("scores.txt", "r") as f:
        # 尝试读取文件
except FileNotFoundError:
    pass  # 文件不存在，跳过
和 C 语言对比：
C 语言手动检查：if (fp == NULL) { ... }
Python 用 try...except 捕获错误，程序不会崩溃

6. datetime 模块（获取时间）

from datetime import datetime

# 获取当前时间
now = datetime.now()

# 格式化时间
time_str = now.strftime("%Y-%m-%d %H:%M:%S")
# 输出：2026-06-24 15:30:45

格式说明：

  • %Y - 年份（4 位）
  • %m - 月份（01-12）
  • %d - 日期（01-31）
  • %H - 小时（00-23）
  • %M - 分钟（00-59）
  • %S - 秒（00-59）

7. random 模块（随机数）

import random

# 生成 1 到 100 的随机整数（包含 1 和 100）
number = random.randint(1, 100)

8. 浮点数精度控制

# 问题：除法得到很多小数位
avg = 253 / 3  # 84.33333333333333

# 解决：用 :.2f 保留 2 位小数
print(f"平均分：{avg:.2f}")  # 平均分：84.33

三、重点问题解答

Q1: scores[name] = score 是什么意思？

答：往字典里添加或修改一对"键-值"。

  • scores 是字典
  • name 是键（比如 "张三"）
  • score 是值（比如 85）
  • 键不存在→添加新项；键存在→修改值

Q2: for name, score in scores.items() 是什么意思？

答：遍历字典，同时拿到键和值。

  • scores.items() 返回所有"键-值"对
  • 每次循环 name 是键，score 是值
  • 注意：items 后面必须加 ()，因为它是方法

Q3: readlines() 是逐行读吗？

答：不是！readlines() 是一次性读取所有行，返回列表。

  • 逐行读用 for line in f
  • readlines() 把整个文件读进内存
  • 大文件推荐用 for line in f（省内存）

Q4: split() 函数输出是什么？

答：把字符串切成多段，返回列表。

line = "张三,85"
parts = line.split(",")  # ["张三", "85"]
name, score = line.split(",")  # 直接拆成两个变量

Q5: 为什么要 strip() 去换行符？

答：文件每行末尾有看不见的 \n，不去掉的话 int("85\n") 会报错。

line = "张三,85\n"
line = line.strip()  # "张三,85"（去掉 \n）
name, score = line.split(",")
scores[name] = int(score)  # ✅ 成功

Q6: try...except 是什么？

答：Python 的错误处理机制，防止程序遇到错误就崩溃。

  • try 里放可能出错的代码
  • except 捕获特定错误，程序不会崩溃
  • pass 表示什么都不做

Q7: from datetime import datetime 是头文件吗？

答：类似但不完全是，Python 里叫"导入模块"。

C 语言：#include <stdio.h>（编译前包含头文件）
Python：import datetime（运行时加载模块）

Q8: 为什么平均分有很多小数位？

答：Python 除法自动返回浮点数，用 :.2f 控制精度。

avg = sum(scores.values()) / len(scores)
print(f"平均分：{avg:.2f}")  # 保留 2 位小数

四、常见错误总结

1. 方法忘记加括号 
# ❌ 错误
for name, score in scores.items:
now = datetime.now.strftime(...)

# ✅ 正确
for name, score in scores.items():
now = datetime.now().strftime(...)
2. 文件模式用错 
# ❌ 日记本用 "w" 会清空之前的内容
with open("diary.txt", "w") as f:

# ✅ 日记本应该用 "a" 追加
with open("diary.txt", "a") as f:
3. 忘记 strip() 去换行符 
# ❌ 会报错：ValueError
score = int("85\n")

# ✅ 先 strip() 再转换
line = line.strip()
score = int(score)
4. print 多打印换行 
# ❌ 每行之间会多一个空行
for line in f:
    print(line)

# ✅ 用 end="" 防止多余换行
for line in f:
    print(line, end="")
5. 中英文符号混淆 
# ❌ 中文逗号、没有等号
print(line，end"")

# ✅ 英文逗号、有等号
print(line, end="")
