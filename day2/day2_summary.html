2. 运行 Python 文件的基本流程

Ctrl + S
python day2.py

如果报错：

意思是：当前 PowerShell 所在文件夹里没有 day2.py。

解决方法：

dir

先看当前文件夹里有没有 day2.py。如果没有，就创建：

notepad day2.py

3. if 判断

Python 的判断写法：

score = 85

if score >= 60:
    print("及格")
else:
    print("不及格")

对应 C 语言大概是：

int score = 85;

if (score >= 60) {
    printf("及格");
} else {
    printf("不及格");
}

区别：Python 不用大括号 {}，靠缩进判断代码属于谁。

4. 多条件判断：elif

Python 里的 elif 相当于 C 里面的 else if。

score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")

5. input 输入

input() 可以让用户输入内容。

score = input("请输入你的成绩：")
print(score)
注意：input() 得到的默认是字符串，不是数字。

如果要和数字比较，需要转成整数：

score = input("请输入你的成绩：")
score = int(score)

6. for 循环

输出 0 到 4：

for i in range(5):
    print(i)

输出 1 到 5：

for i in range(1, 6):
    print(i)

range(1, 6) 的意思是：从 1 开始，到 6 之前结束，所以包括 1、2、3、4、5。

7. 计算 1 到 100 的和

total = 0

for i in range(1, 101):
    total = total + i

print("1 到 100 的和是", total)

也可以写成：

total = 0

for i in range(1, 101):
    total += i

print("1 到 100 的和是", total)

total += i 等价于 total = total + i。

8. while 循环

while 的意思是：只要条件成立，就一直执行。

count = 1

while count <= 5:
    print(count)
    count += 1

9. break

break 的意思是：提前结束循环。

while True:
    text = input("请输入内容，输入 q 退出：")

    if text == "q":
        break

    print("你输入的是：", text)

print("程序结束")

你今天问到的问题

问题 1：缩进是 2 个空格会出问题吗？

不一定会出问题。Python 只要求同一层缩进保持一致。

例如下面代码通常也能运行：

if score >= 60:
  print("及格")
else:
  print("不及格")

但是新手强烈建议统一用 4 个空格：

if score >= 60:
    print("及格")
else:
    print("不及格")
记忆：Python 缩进可以不是 4 个空格，但新手统一用 4 个空格最安全。

问题 2：为什么 VS Code 里 Tab 一下是两个空格？

这是 VS Code 的设置问题。右下角可能显示 Spaces: 2 或 Tab Size: 2。

解决：

  1. 点击 VS Code 右下角的 Spaces: 2。
  2. 选择 Indent Using Spaces。
  3. 选择 4。

之后按一次 Tab，就会变成 4 个空格。

问题 3：VS Code 里写完代码怎么保存？

最常用的方法：

Ctrl + S

保存成功后，文件名旁边的小圆点会消失。

完整流程：

  1. 在 VS Code 写代码。
  2. 按 Ctrl + S 保存。
  3. 回到 PowerShell。
  4. 运行 python day2.py。

问题 4：变量 total 怎么直接输出了？

因为 total 前面已经被创建过了：

total = 0

然后循环里不断更新它：

for i in range(1, 101):
    total = total + i

最后 total 里面保存的就是 5050，所以可以直接输出：

print("1 到 100 的和是", total)

问题 5：C 语言前面要有变量声明，Python 为什么不用？

C 语言需要先写类型：

int total = 0;
double length = 2.5;

Python 不用提前声明类型，直接赋值：

total = 0
length = 2.5

Python 会根据右边的值自动判断类型。

问题 6：C 的 printf 和 Python 的 print 有什么区别？

C 语言常用格式占位符：

int total = 5050;
printf("1 到 100 的和是 %d\n", total);

%d 表示整数，%f 表示小数，%s 表示字符串。

Python 可以直接用逗号输出变量：

total = 5050
print("1 到 100 的和是", total)

以后还会常用 f-string：

total = 5050
print(f"1 到 100 的和是 {total}")

Day 2 作业

作业 1：判断成年人

age = input("请输入年龄：")
age = int(age)

if age >= 18:
    print("成年人")
else:
    print("未成年人")

作业 2：计算 1 到 n 的和

n = input("请输入 n：")
n = int(n)

total = 0

for i in range(1, n + 1):
    total += i

print("1 到", n, "的和是", total)

作业 3：简易密码验证

password = "123456"

for i in range(3):
    user_input = input("请输入密码：")

    if user_input == password:
        print("登录成功")
        break
    else:
        print("密码错误")

一句话总结

Day 2 的重点不是背语法，而是理解：Python 靠缩进组织代码，变量不用提前写类型，print 可以直接输出变量，循环可以让电脑重复帮你干活。
